Algorithm Methodology & Mathematical Specification

{% if active_key == 'linear' %} Ordinary Least Squares (OLS) Linear Regression: Minimizes the sum of squared differences between observed customer balances $y_i$ and linear predictions $\hat{y}_i = X_i\beta$:
$$\min_{\beta} \sum_{i=1}^n (y_i - X_i\beta)^2$$ Calculates unbiased estimates under Gauss-Markov assumptions without shrinkages. {% else %} Ridge Regression (Tikhonov L2 Regularization): Augments the residual sum of squares loss with an L2 norm penalty on weight magnitudes ($\alpha = 1.0$):
$$\min_{\beta} \left( \sum_{i=1}^n (y_i - X_i\beta)^2 + \alpha \|\beta\|_2^2 \right)$$ Stabilizes coefficient estimations when banking predictors exhibit multi-collinearity. {% endif %}

Interpretation: Balance has substantial variation beyond these input features. The reported R² should be read honestly as the fraction of balance variation explained by this simple linear experiment.
